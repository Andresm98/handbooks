🎭 Patrones de Renderizado

Patrón Dónde se genera el HTML Cuándo Frameworks Ideal para
SSR — Server Side Rendering Servidor En cada request (runtime) Next.js, Nuxt, Remix SEO, datos dinámicos por usuario
SSG — Static Site Generation Servidor (build time) Durante el build Next.js, Gatsby, Astro Blogs, docs, landing pages
CSR — Client Side Rendering / SPA Navegador En tiempo de ejecución (JS) React, Vue, Angular Apps interactivas, dashboards internos
ISR — Incremental Static Regeneration Servidor (revalidación) Build + revalidación periódica Next.js E-commerce, contenido semi-estático
PWA — Progressive Web App Mixto Service Worker + cache Cualquier framework Offline support, instalable en dispositivo
💡
PWA no recomendada cuando: la app necesita acceso profundo a hardware (Bluetooth, NFC, acelerómetro, GPS en background). Para esos casos, una app nativa móvil es la mejor opción.

🧩 Microfrontends

Extensión del concepto de microservicios al frontend. Cada equipo es dueño de una parte independiente de la UI, con su propio stack tecnológico y ciclo de deploy.

Ventajas

  • Múltiples tecnologías en mismo frontend (React + Vue + Angular)
  • Deploys independientes por equipo
  • Escalado de equipos sin fricción
  • Aislamiento de fallos

Implementación

  • Module Federation: Webpack 5 comparte módulos en runtime
  • Web Components: Custom Elements nativos del browser
  • iFrames: aislamiento total, UX limitada
  • Single-SPA: framework de orquestación
