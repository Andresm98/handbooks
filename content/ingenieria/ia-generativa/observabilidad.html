Un sistema agéntico sin observabilidad es una caja negra no determinista en producción — el peor escenario posible para un entorno regulado. La disciplina de evals y tracing es tan importante como el diseño del agente mismo.

Qué observar

DimensiónQué mide
Tracing de pasosCada decisión, tool call y resultado intermedio del agente, para poder reconstruir por qué llegó a una respuesta
Evals de calidadComparación contra un dataset de referencia: precisión, alucinación, adherencia a formato
Costo y latenciaTokens consumidos y tiempo por paso, crítico cuando hay multiagente o paralelismo
Tasa de intervención humanaCon qué frecuencia el agente escala a un humano; indicador de madurez del sistema
Drift de comportamientoSi el mismo prompt produce resultados distintos con el tiempo (cambios de modelo, cambios de datos RAG)
Para entornos regulados
La trazabilidad de decisiones de un agente (qué documento recuperó, qué herramienta invocó, con qué parámetros) no es solo buena práctica de ingeniería: en banca suele ser un requisito de auditoría equivalente a un log de transacciones.

La industria converge en las convenciones semánticas de OpenTelemetry para IA generativa (atributos estándar para modelo, tokens, operaciones de herramientas), lo que permite enviar trazas de agentes al mismo backend que el resto de tus servicios. Registra el contenido de prompts y respuestas solo donde la política de datos lo permita: pueden contener datos personales.

Observabilidad y trazabilidad

Todo flujo agéntico de producción debe trazar cada llamada al LLM, cada tool call, y cada paso del pipeline con su latencia, tokens consumidos, y costo. LangSmith y Langfuse ofrecen esta capacidad out-of-the-box.

Métricas clave a monitorear

Latencia P50/P95/P99 por etapa, tokens por query, costo por query, retrieval precision (via feedback loops), tasa de abstención (cuando el modelo dice "no sé"), y tasa de error por tipo de tool.

AI GATEWAY: EL PATRÓN QUE FALTA EN LA MAYORÍA

Un AI Gateway centraliza todas las llamadas a modelos de IA en la organización, de la misma forma que un API Gateway centraliza las llamadas HTTP. Es la pieza más importante que la mayoría de los sistemas de IA ignoran.

# AI Gateway: centraliza llamadas, añade observabilidad y control
class AIGateway:
    def __init__(self):
        self.semantic_cache = SemanticCache(threshold=0.95)
        self.rate_limiter   = RateLimiter(requests_per_minute=100)
        self.cost_tracker   = CostTracker(budget_usd=500)
        self.tracer         = LangFuseTracer()

    async def complete(self, request: CompletionRequest) -> CompletionResponse:
        # 1. Verificar rate limit por tenant
        await self.rate_limiter.check(request.tenant_id)

        # 2. Semantic cache — misma pregunta, misma respuesta
        cached = await self.semantic_cache.get(request.prompt)
        if cached:
            return cached  # ~$0 vs $0.05 por request cacheado

        # 3. Model routing inteligente (económico para queries simples)
        model = self.route_to_model(request)
        # Queries simples → GPT-4o-mini ($0.00015/1K tokens)
        # Queries complejas → GPT-4o ($0.005/1K tokens)

        # 4. Llamada al modelo con tracing
        with self.tracer.trace(request) as span:
            response = await model.complete(request)
            span.record(tokens=response.usage, cost=response.cost)

        # 5. Cost tracking — alertar si se supera el budget
        await self.cost_tracker.record(response.cost, request.tenant_id)

        # 6. Guardar en caché para futuros requests similares
        await self.semantic_cache.set(request.prompt, response)

        return response
Modelos relacionados

Los sistemas de IA usan patrones arquitectónicos establecidos: Event-Driven Architecture para pipelines de indexación asíncrona. CQRS con un modelo de escritura (ingesta de documentos) y lectura (vector search + generation). Hexagonal Architecture para aislar los LLMs como adapters externos (si cambias de OpenAI a Anthropic, solo cambia el adapter). Los Workflow Engines como Temporal son ideales para orquestación de agentes con durabilidad y retry garantizados.
