Los frameworks resuelven la "fontanería" de los agentes: el loop, el estado, la memoria, la conexión de herramientas, las pausas para aprobación humana y la observabilidad. El panorama cambia cada pocos meses (se fusionan proyectos, aparecen SDKs de cada proveedor), así que importa más entender las categorías que memorizar nombres.

Nota de arquitectura Distingue entre frameworks de agentes y motores de workflow. En sistemas de misión crítica es común envolver los pasos no deterministas del LLM dentro de un motor de workflow determinista: reintentos, idempotencia, auditoría y reanudación de nivel productivo que los frameworks de agentes no siempre garantizan por sí solos.

Criterios de selección

  • ¿Necesitas un framework? Para un agente con pocas herramientas, el SDK del proveedor y 50 líneas de loop propio son más fáciles de depurar que cualquier abstracción.
  • Durabilidad: ¿cómo persiste y reanuda el estado? ¿Qué pasa si el proceso muere a mitad de una herramienta?
  • Human-in-the-loop: ¿puede pausar, esperar horas una aprobación y continuar?
  • Observabilidad: ¿emite trazas estándar (OpenTelemetry) o solo hacia su propia plataforma?
  • Portabilidad: ¿te ata a un proveedor de modelos o de nube?
  • Madurez: frecuencia de cambios incompatibles, comunidad, soporte. Un framework que cambia su API cada trimestre es deuda técnica.

Ejemplo: un grafo de estado con LangGraph

LangGraph modela flujos agénticos como grafos de estado donde cada nodo es una función (o llamada al LLM) y las aristas determinan el flujo de control. El estado se persiste automáticamente, permitiendo pausas, checkpoints y reanudaciones.

Componentes del grafo

Concepto Descripción Analogía
State Objeto Python con toda la información del flujo Variables globales del programa
Node Función que recibe y modifica el state Función en un programa
Edge Transición entre nodos Llamada a función / goto
Conditional edge Edge que depende del state actual if/else
Checkpointer Persistencia automática del estado Guardar progreso 
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated
import operator

class AgentState(TypedDict):
    messages: Annotated[list, operator.add]
    context: list[str]
    final_answer: str | None

def retrieve(state: AgentState) -> AgentState:
    query = state["messages"][-1].content
    chunks = vector_store.search(query, k=5)
    return {"context": chunks}

def generate(state: AgentState) -> AgentState:
    response = llm.invoke(state["messages"] + state["context"])
    return {"final_answer": response.content}

def should_continue(state: AgentState) -> str:
    if "[BUSCAR MÁS]" in state.get("final_answer", ""):
        return "retrieve"
    return "end"

graph = StateGraph(AgentState)
graph.add_node("retrieve", retrieve)
graph.add_node("generate", generate)
graph.set_entry_point("retrieve")
graph.add_edge("retrieve", "generate")
graph.add_conditional_edges("generate", should_continue,
    {"retrieve": "retrieve", "end": END})
