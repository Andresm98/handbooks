🔌 Configuración Dinámica de Servidores

DHCP (Dynamic Host Configuration Protocol) es el protocolo que asigna dinámicamente configuración de red (IP, gateway, DNS) a dispositivos/servidores. Es la definición de "dynamic server configuration".

Static vs Dynamic Configuration

  • Static: IP y config asignadas manualmente
  • Dynamic (DHCP): asignación automática al conectarse

Source IP Hash en Load Balancing

Usa el IP del cliente para determinar siempre el mismo servidor. Garantiza session persistence (sticky sessions). Ideal cuando el servidor guarda estado de sesión localmente.

📡 CDN — Content Delivery Network

Red de servidores distribuidos globalmente que cachean contenido cerca del usuario. Reduce latencia y carga en el origin server.

Qué cachear en CDN

  • Assets estáticos (JS, CSS, imágenes, fuentes)
  • Videos y archivos grandes
  • Respuestas de API con TTL definido
  • Páginas SSG

Servicios CDN

  • AWS CloudFront
  • Azure CDN / Azure Front Door (con WAF)
  • GCP Cloud CDN
  • Cloudflare (multi-cloud)
  • Akamai (enterprise)
