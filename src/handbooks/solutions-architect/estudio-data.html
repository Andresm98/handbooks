🔍 SQL vs NoSQL — Cuándo usar cada uno

Aspecto SQL (Relacional) NoSQL
Estructura Schema fijo, tablas, relaciones Schema flexible (document, key-value, graph, column-family)
Consistencia ACID completo — fuerte BASE (Basically Available, Soft state, Eventually consistent)
Escalado Vertical principalmente (horizontal complejo) Horizontal nativo (sharding)
Transacciones ✅ Transacciones complejas multi-tabla ❌ Limitado (problema en finanzas)
Queries SQL estándar, JOINs complejos APIs propias, sin JOINs (denormalización)
Latencia NoSQL Más latencia en alta escala ✅ Baja latencia a escala masiva
Casos de uso Finanzas, ERP, CRM, sistemas legacy Redes sociales, IoT, catálogos, gaming
Ejemplos PostgreSQL, MySQL, MSSQL, Oracle MongoDB, DynamoDB, Cassandra, Redis

Tipos de NoSQL

📄 Document

Datos como documentos JSON/BSON. Flexible, bueno para datos heterogéneos.

MongoDB, Firestore, CouchDB

🔑 Key-Value

Acceso ultra-rápido por clave. Ideal para caché y sesiones.

Redis, DynamoDB, Memcached

📊 Column-Family

Datos organizados por columnas. Excelente para series de tiempo y analytics.

Cassandra, HBase, Bigtable

🕸️ Graph

Nodos y relaciones. Ideal para redes sociales, recomendaciones, fraude.

Neo4j, Amazon Neptune, ArangoDB

⚠️
Limitación crítica NoSQL en finanzas: Las bases NoSQL tienen menor rendimiento en transacciones complejas y consistencia fuerte. Los sistemas financieros requieren ACID completo → preferir PostgreSQL, Aurora, o Spanner.

⚡ Caching — Estrategias y Tipos

Por qué usar caché

  • ✅ Reducir latencia de consultas (evitar round-trip a DB)
  • ✅ Mejorar responsividad de la aplicación
  • ✅ Disponibilidad de datos si DB temporalmente no disponible
  • ✅ Reducir carga en base de datos

Patrones de Caché

  • Cache-Aside: app gestiona cache manualmente
  • Read-Through: cache delante de DB, transparente
  • Write-Through: escribe en cache + DB sincrónicamente
  • Write-Behind: escribe en cache, DB async (eventual)

Distributed Cache (Redis, Memorystore) es el mecanismo clave para minimizar latencia en sistemas distribuidos de alta disponibilidad.
